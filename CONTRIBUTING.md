# Contributing to signnow-mcp

Thank you for your interest in contributing! We welcome all contributions — bug reports, feature requests, documentation improvements, and code changes.

## Getting Started

1. **Fork** the repository and clone your fork locally.
2. **Install dependencies:**
   ```bash
   poetry install
   ```
3. **Create a branch** for your change:
   ```bash
   git checkout -b feature/my-feature
   ```
4. **Make your changes** and ensure they follow the existing code style.
5. **Test your changes** before submitting.
6. **Commit** using [Conventional Commits](https://www.conventionalcommits.org/):
   ```
   feat: add new tool for document merging
   fix: handle expired token gracefully
   docs: update setup instructions
   ```
7. **Push** your branch and open a Pull Request.

## Branch Naming

Use prefixed branch names:

- `feature/` — new functionality
- `fix/` — bug fixes
- `chore/` — maintenance tasks
- `docs/` — documentation changes

## Code Style

- Follow existing patterns in the codebase.
- Use type hints where possible.
- Write clear docstrings for public functions and classes.

## Reporting Bugs

Please use the [bug report template](https://github.com/musictechlab/signnow-mcp/issues/new?template=bug_report.yml) when filing issues.

## Suggesting Features

Please use the [feature request template](https://github.com/musictechlab/signnow-mcp/issues/new?template=feature_request.yml) when proposing new features.
